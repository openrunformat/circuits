# Open Run Format circuit registry

Open registry of circuits and layouts for [Open Run Format](https://github.com/openrunformat/spec).

- Data (`circuits/`, `schema/`, `dist/`, `docs/`, `tests/fixtures/`): CC0-1.0, see `LICENSE`.
- Tools (`tools/`): Apache-2.0, see `tools/LICENSE` and `tools/NOTICE`.

Validate the registry: `dotnet run --project tools/OrfCircuits -- validate .`
