# Contributing to the circuit registry

Thank you for helping. The registry is only useful if every gate can be trusted and every piece of data can be
reused freely, so the rules below are strict.

## Pull requests

- **One circuit per pull request.** Add or change one file, `circuits/<CC>/<name>.json`.
- **Do not edit `dist/`.** The index is regenerated by the continuous integration after a merge; a pull request that
  touches `dist/` fails its checks.
- Run `dotnet run --project tools/OrfCircuits -- validate .` before you open the pull request. The same check runs in
  the continuous integration.

## Identifiers

- The id is `<CC>-<name>`: the ISO 3166-1 alpha-2 code of the country and a name of 2 to 32 characters (`a-z`, `0-9`,
  `-`; starting and ending with a letter or digit; no `--`). The file name is `<name>.json` in folder `<CC>`.
- Layout ids follow the same rules as names (`gp`, `national`, `full`).
- Generate every `uid` (circuit and layouts) with `dotnet run --project tools/OrfCircuits -- uid`. **A uid never
  changes**, not even when the circuit is renamed.
- **Renaming:** change `id` (and the file name) and add the old id to `aliases`. Applications keep resolving it.
- **New geometry:** when a layout changes (new finish line, new chicane), do not edit the existing version: close it
  with `to` and add a version whose `id` is the year (`2023`) or year-month (`2023-04`) of its `from` date.
  Periods are `[from, to)` and must not overlap. A layout with a single version may omit `id`, `from` and `to`.

## Provenance

Every gate cites an entry of the file's `provenance` list. Accepted sources:

| `method` | What | Requirements |
|---|---|---|
| `measured-gps` | Your own GPS measurements or laps | `contributor`, `date` |
| `orthophoto` | Points measured by you on an orthophoto with an open licence | `source`, `licence` (`CC0-1.0` or `CC-BY-4.0`), `attribution` for CC BY |
| `official` | Non-geometric data published by the circuit (e.g. the official length) | `url`; never for gates |

- The national orthophoto of Spain (PNOA, Instituto Geográfico Nacional, CC BY 4.0) may be used **only to measure
  points**, with `source`, `licence: "CC-BY-4.0"` and the attribution text the source requires. The same applies to
  other orthophotos with a CC0 or CC BY 4.0 licence.
- **Not accepted:**
  - geometry or any data from OpenStreetMap (ODbL);
  - databases under non-commercial or share-alike licences;
  - data from vehicle manufacturers or their applications — neither geometry nor identifiers;
  - data copied from websites without a licence that allows it.
- Declare the provenance of everything you contribute. If in doubt, ask in the pull request before measuring.

## External ids

`external` links a circuit or layout to an id in a public database (`wikidata` today). To accept a new system, open a
pull request that adds it to `schema/systems.json` and explain why the identifier is public and what licence the
database uses.

## Review checklist (maintainers)

- [ ] Provenance is credible: method, source, contributor and date make sense for this circuit.
- [ ] CC BY sources carry the exact attribution text the source requires.
- [ ] Gates are on the track: about the width of the asphalt, across the track, at the painted line.
- [ ] Gate point 1 is on the left edge and point 2 on the right edge, looking in the direction of travel.
- [ ] Nothing comes from vehicle manufacturers, OpenStreetMap or sources without a compatible licence.
- [ ] Ids follow the rules above; renamed ids are kept in `aliases`; no uid was changed.
